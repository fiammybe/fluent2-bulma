# Changelog

Notable changes to fluent2-bulma are documented here. Release notes are published with each
GitHub Release.

## [0.1.0] - Initial public release

- Theme Bulma 1.x elements, forms, helpers, and components with Fluent 2 tokens.
- Provide light and dark themes, compact and comfortable density, Sass tokens, and CSS.
- Include an interactive component gallery, optional JavaScript enhancements, and icons.
- Publish as `@fiammybe/fluent2-bulma` with Bulma as a peer dependency.
