Migrate from plain Bulma

The theme is designed as a progressive visual change: keep Bulma 1.x and your existing Bulma class names, then load the Fluent stylesheet after Bulma.

  1. Install @fiammybe/fluent2-bulma alongside Bulma.
  2. Put Bulma in the bulma cascade layer and let the theme’s fluent2 layer follow it.
  3. Review any app-specific CSS that overrides Bulma components and update as needed.
  4. Add .is-comfortable to a region or form when the 2.5rem comfortable controls suit that interface better than the compact default. 
@layer bulma, fluent2;
@import url('bulma/css/bulma.css') layer(bulma);
@import url('@fiammybe/fluent2-bulma/css/fluent2-bulma.css');

<button class="button is-primary">Save changes</button>

Bulma elements, forms, layout, and helper classes remain the primary interface. Dedicated components such as badges and avatars use .fluent-* classes; JavaScript enhancements are opt-in and target data-fluent-* attributes. See the gallery for examples and copyable snippets.
