Getting started

Bulma is a peer dependency. Install it alongside the theme:

npm install bulma @fiammybe/fluent2-bulma

Load Bulma in a lower-priority cascade layer. The Fluent theme creates its own layer:

@layer bulma, fluent2;
@import url('bulma/css/bulma.css') layer(bulma);
@import url('@fiammybe/fluent2-bulma/css/fluent2-bulma.css');

Use a CDN

Pin both packages to explicit versions for reproducible deployments:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bulma@1.0.4/css/bulma.min.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@fiammybe/fluent2-bulma@0.1.0/css/fluent2-bulma.css">

For CDN use, load the Bulma link first and the Fluent 2 × Bulma link second. For cascade layer control, use the npm stylesheet import shown above.

Compile with Sass

Use the Sass entry point to customize build-time tokens:

@use '@fiammybe/fluent2-bulma' with (
  $fluent-brand-color: #0f6cbd
);

The package also exports @fiammybe/fluent2-bulma/tokens for Sass token maps and @fiammybe/fluent2-bulma/tokens.css for a tokens-only stylesheet.

The default compact density uses 2rem controls. Add is-comfortable to opt into 2.5rem controls. See the theming guide for theme and override options.
