Browser support

We support the final stable releases of Chrome, Edge, Firefox, and Safari from the last two months. This rolling window follows current browser releases rather than maintaining a fixed list of old versions.

The theme uses modern CSS features such as cascade layers and custom properties. Enhanced controls use progressive browser APIs where available; core navigation, forms, and content remain usable without JavaScript. See the accepted browser-support decision.

Report an issue with the browser and version, operating system, and a minimal reproduction.

Unofficial community project; not affiliated with Microsoft or Bulma.
