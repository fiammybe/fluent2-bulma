Theming

Set the brand color in Sass

@use '@fiammybe/fluent2-bulma' with (
  $fluent-brand-color: #0f6cbd
);

Override the runtime brand token

:root {
  --fluent-brand-color: #6750a4;
}

Color, typography, spacing, radius, shadow, and motion values are available as Fluent custom properties. Import @fiammybe/fluent2-bulma/tokens to access Sass token maps or include @fiammybe/fluent2-bulma/tokens.css for tokens without component styles.

Override styles with cascade layers

Declare your layer after fluent2 to override theme rules predictably. Keep third-party Bulma rules in the lower-priority layer. 

@layer bulma, fluent2, app;

@import url('bulma/css/bulma.css') layer(bulma);
@import url('@fiammybe/fluent2-bulma/css/fluent2-bulma.css');

@layer app {
  :root {
    --fluent-brand-color: #6750a4;
  }

  .button.is-primary {
    border-radius: 999px;
  }
}

Unlayered author rules outrank layered author styles; place custom rules in your declared app layer when you want this explicit ordering.
